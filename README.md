# Portofolio v2 Akhmad Alfin Izzatillah

Website portofolio pribadi yang saya buat di Kelas Industri UBIG
(Paket 1, Minggu 01 sampai 09).

Versi ini adalah Portofolio v2 yang responsif dan interaktif
menggunakan HTML, CSS, dan JavaScript.

## Tampilan

![Tampilan Portofolio](img/proyek-portofolio.png)

## Fitur

- Halaman Beranda berisi profil, hobi, cita-cita,
  jadwal belajar, dan daftar keahlian.
- Halaman Proyek menampilkan daftar proyek
  beserta filter kategori.
- Halaman Kontak berisi formulir kontak
  dengan penghitung karakter pesan.
- Mode gelap dan terang.
- Tampilan responsif untuk HP, tablet, dan laptop.
- Integrasi GitHub API.
- Data proyek dan keahlian menggunakan JSON.

## Teknologi

- HTML5
- CSS3 (Flexbox, Media Query, dan variabel CSS)
- JavaScript (DOM, Event, Fetch, Async/Await)
- JSON
- Git dan GitHub
- Vercel
